3. Для последнего пункта можно ``script.py`` переделать так, чтобы значение для **N** присваивалось из командной строки (``N=int(sys.argv[1]``). Вот пример из другой работы, как запуск обернули в функцию с профилированием:
```python
def run_script(N):
    cmd = ["python", "script.py", str(N)]

    start_time = time.perf_counter()
    process = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    process.communicate()
    elapsed_time = time.perf_counter() - start_time

    mem_usage = memory_usage((subprocess.run, (cmd,)), max_usage=True)

    return elapsed_time, mem_usage
```

Можете запустить это все в цикле, если хотите. Там можно будет увидеть что для некоторых **N** время исполнения заметно быстрее, потому что в коде используется преобразование Фурье из ``numpy``. Он для определенных размеров сигнала гораздно быстрее работает. Просто в текущей вашей реализации это трудно будет увидеть. Но тем не менее пункт считается выполненным.
